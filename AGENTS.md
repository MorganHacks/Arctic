# UI icons

Use Hugeicons for all new or updated interface icons: `@hugeicons/react` with
`@hugeicons/core-free-icons`. Choose the icon that directly describes the action
or destination, using the rounded stroke style consistently. Do not add other
icon libraries or hand-drawn SVG interface icons.

In portaladmin, use `components/ui/icon.tsx` for consistent sizing, stroke width,
and decorative-icon accessibility. Icon-only controls must have an accessible
label. Logos, illustrations, and generated QR codes are not interface icons.

# Code style

Do not add code comments unless the user explicitly asks for them.
